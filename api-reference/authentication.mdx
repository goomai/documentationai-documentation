---
title: "Authentication"
description: "How to authenticate requests to the API."
---

All requests require a bearer token sent in the `Authorization` header.

## Request

<CodeGroup>
```bash cURL
curl https://api.example.com/v1/users \
  -H "Authorization: Bearer $API_KEY"
```

```js JavaScript
const res = await fetch("https://api.example.com/v1/users", {
  headers: { Authorization: `Bearer ${process.env.API_KEY}` },
});
```

```python Python
import os, requests

res = requests.get(
    "https://api.example.com/v1/users",
    headers={"Authorization": f"Bearer {os.environ['API_KEY']}"},
)
```
</CodeGroup>

## Parameters

<ParamField path="Authorization" param-type="string" required="true">
  Bearer token issued from your dashboard. Prefix the token with `Bearer `.
</ParamField>

<ParamField path="limit" param-type="integer" required="false">
  Maximum number of records to return. Defaults to `20`, maximum `100`.
</ParamField>

## Response

```json
{
  "data": [{ "id": "usr_123", "email": "user@example.com" }],
  "has_more": false
}
```

## Errors

| Status | Meaning |
|--------|---------|
| `401`  | Missing or invalid token |
| `403`  | Token lacks the required scope |
| `429`  | Rate limit exceeded |

<Callout kind="warning">
  Never commit an API key to your documentation repository. Use an environment
  variable, as in the examples above.
</Callout>
