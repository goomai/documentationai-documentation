---
title: "Customization"
description: "Brand colors, navigation structure, and custom CSS."
---

Three things control how your site looks: the color tokens, the navigation tree,
and optional custom CSS.

## Colors

Set your brand color per theme in `documentation.json`:

```json
{
  "colors": {
    "light": { "brand": "#3143e3" },
    "dark": { "brand": "#85a1ff" }
  }
}
```

## Navigation

Navigation is a tree of tabs, groups, and pages. A tab takes exactly one kind of
child: `groups`, `pages`, or `dropdowns`.

```json
{
  "tab": "Documentation",
  "icon": "book",
  "groups": [
    {
      "group": "Getting Started",
      "pages": [
        { "title": "Introduction", "path": "getting-started/introduction" }
      ]
    }
  ]
}
```

Icons come from the Lucide icon library. Page entries also accept `badge`,
`show-sidebar`, `show-toc`, and `content-width` when you need to override the
defaults.

## Custom CSS

For finer control, register a stylesheet and target the platform's stable
`dai-*` class names rather than generated ones:

```json
{
  "customCss": [{ "src": "styles/custom.css" }]
}
```

```css
.dai-breadcrumbs {
  margin-bottom: 16px;
}
```

<Callout kind="info">
  Custom stylesheets load last, so they override the built-in styles. Scope
  dark-mode rules under `.dark`.
</Callout>
