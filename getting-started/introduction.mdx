## How pages work

Every page is an MDX file with YAML frontmatter at the very top. The `title`
field is required:

```mdx
---
title: "Page title"
description: "One line describing the page."
---
```

A page only appears on your site once it is listed in `documentation.json`. The
`path` in the navigation matches the file path without the `.mdx` extension, so
`getting-started/introduction.mdx` is referenced as
`getting-started/introduction`.

<Callout kind="info" collapsed="false">
  Add, rename, or remove a page and you must update `documentation.json` in the
  same change, or the page will not show up in the sidebar.
</Callout>
