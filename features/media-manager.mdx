## Overview

Media Manager gives you a built-in library for images, video, and file uploads. Open it from the editor sidebar to upload, preview, replace, and insert visual assets without leaving your documentation workflow.

## Accessing the Media Manager

Open a document in the editor, then select **Media** from the editor sidebar. The media library opens alongside your document so you can browse existing files or upload new ones.

## Uploading media

Upload one file or several files at once with drag and drop.

<Steps>
  <Step title="Open the media sidebar" icon="folder" title-type="p">
  Open the document where you want to manage media, then select **Media** in the editor sidebar.
  </Step>
  <Step title="Add your files" icon="upload" title-type="p">
  Drag files into the upload zone, or click the zone to browse for files. Media Manager supports multi-file drag and drop.
  </Step>
  <Step title="Wait for the upload to finish" icon="cloud" title-type="p">
  Keep the media sidebar open while your files upload and process.
  </Step>
  <Step title="Confirm the files in your library" icon="check-circle" title-type="p">
  Each completed upload appears in the media library and is ready to preview or insert into your document.
  </Step>
</Steps>

<Callout kind="alert">
Supported file types include images, video, and documents. Large files may take longer to upload and process.
</Callout>

## Replacing media

Replace an existing media file from its details view when you need to update an asset without changing the pages that use it. Media Manager preserves the existing page references while serving the replacement file.

## Storage quotas

Your plan determines how much storage your media library can use. Monitor your storage usage in the media settings and remove files you no longer need when you approach the limit.

<Callout kind="info">
When your storage quota is nearly full, open **Settings** to review available upgrade options.
</Callout>

## Audit logging

Media changes are tracked with audit logging, including upload and replacement activity. Use the audit history to review changes made to your media library.
