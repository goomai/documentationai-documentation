## Page Actions

Page Actions controls which quick action buttons appear in the sidebar of your published documentation. Use it to show or hide individual actions based on how you want readers to interact with each page. Changes are saved to your documentation configuration and apply after you publish.

## Available actions

Choose from these sidebar actions, in this order:

- Copy page
- Download as PDF
- View as Markdown
- Open in Claude
- Open in ChatGPT
- Open in Perplexity
- Open in Grok
- Copy MCP server URL

## How it works

<Callout kind="info">

All page actions are enabled by default. If you leave every action on, no extra configuration is needed.

</Callout>

When you turn one or more actions off, the configuration stores only the action IDs that remain enabled. This keeps your documentation configuration clean while still letting you control exactly what appears in the published sidebar.

## Editing page actions

<Steps>
  <Step title="Open Page Actions in the editor" icon="settings" title-type="p">

  Open the editor's settings sidebar and find the **Page Actions** section.

  </Step>
  <Step title="Toggle each action on or off" icon="toggle-left" title-type="p">

  Turn individual switches on or off for each action you want to show or hide in the published sidebar.

  </Step>
  <Step title="Publish your documentation" icon="upload" title-type="p">

  Publish your documentation to apply the updated sidebar actions to the live site.

  </Step>
</Steps>

<Callout kind="alert">

Changes do not affect the live sidebar until you publish.

</Callout>

## SEO overrides with frontmatter

Two optional frontmatter fields let you control what search engines and social media platforms see, independently of the visible page heading and description:

| Field | Controls |
| --- | --- |
| `metaTitle` | Browser tab title, Open Graph title, Twitter card title, and JSON-LD headline |
| `metaDescription` | Meta description tag, Open Graph description, and Twitter card description |

If you omit these fields, search engines fall back to the page's `title` and `description` frontmatter values. The visible `<h1>` heading and on-page description are not affected.

```yaml
---
title: Getting Started
description: Set up your first project in minutes.
metaTitle: Getting Started with Documentation.AI
metaDescription: Learn how to create, configure, and publish your first documentation site.
---
```

## Click-to-copy heading links

Every heading with an anchor ID acts as a copy-to-clipboard link. Clicking anywhere on a heading copies the section URL to the clipboard and updates the browser's address bar. A link icon in the margin confirms the copy with a checkmark for one second.

This behavior is built in and requires no configuration.
