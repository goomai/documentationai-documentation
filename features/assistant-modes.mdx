## Assistant Modes

Assistant Modes control how the AI assistant on your published documentation operates. Choose between Pro and Lite to balance the assistant experience with your plan usage.

<Callout kind="info" collapsed="false">

Mode switching is available only to eligible plans. If your plan does not qualify, the assistant runs in Pro mode.

</Callout>

## Plan eligibility

Your subscription determines whether you can switch modes and which mode the assistant uses by default.

| Subscriber type | Can switch modes | Default mode |
| --- | --- | --- |
| Existing paid plans (Standard, Professional, Enterprise) | Yes | Lite |
| New paid plans | No | Pro |
| AppSumo | Yes | Pro |
| Free / Starter | No | Pro |

Organizations that were already on a paid plan when Assistant Modes launched can switch modes and start in Lite mode by default. New subscribers start in Pro mode and cannot switch modes.

<Callout kind="alert" collapsed="false">

If a subscription is canceled or becomes unpaid, the organization is treated as free. The assistant defaults to Pro, and mode switching is no longer available.

</Callout>

## Switching modes

<Steps>
  <Step title="Open documentation settings" icon="settings" title-type="p">

    In the editor, open the settings panel for your documentation site.

  </Step>

  <Step title="Find the Assistant Mode setting" icon="toggle-left" title-type="p">

    If your plan is eligible, you will see a Pro/Lite mode selector. If you do not see it, your plan does not support mode switching.

  </Step>

  <Step title="Choose Pro or Lite" icon="check-circle" title-type="p">

    Select the mode you want, then save your changes.

  </Step>

  <Step title="Publish to apply" icon="upload" title-type="p">

    Publish your documentation so the new mode takes effect on the live site.

  </Step>
</Steps>

## Resetting to default

Reset the assistant mode to your plan's default at any time. Resetting clears your explicit selection and returns the assistant to the mode your subscription currently provides by default.
