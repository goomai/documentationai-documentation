## The building blocks

<Columns cols={2}>

  <Card title="Pages" icon="file-text">

    Every page is an `.mdx` file. Content lives in the repo and is safe to edit.

  </Card>
  <Card title="Navigation" icon="list">

    Sidebar structure comes from `documentation.json`.

  </Card>
  <Card title="Components" icon="layout-grid">

    Reusable blocks like Callouts, Steps, Tabs, and Cards keep pages consistent.

  </Card>
  <Card title="API Reference" icon="code">

    The API tab reads from an OpenAPI spec — either a repo-relative file path like `openapi.yaml` or a remote `https` URL. Use the `openapi-output` field to control where generated pages are placed for URL-based specs.

  </Card>

</Columns>

## Navigation shape (sample)

{

  "groups": [
