<Update label="2026-09-03" description="Role-Based Access Control" tags={["feature"]}>
## What's new
- **Access Control**: Restrict which published documentation pages users can see based on their role. Available under **Settings → Access Control** with JWT or OAuth 2.0 authentication.
- Define custom roles and assign them to pages, groups, or navigation containers. Roles inherit down the navigation tree and can be overridden on individual items.
- Disabling role-based access preserves existing role assignments without enforcing them — toggle it back on to resume enforcement.
- See the [Access Control](/features/access-control) page for setup instructions and role inheritance details.
</Update>
